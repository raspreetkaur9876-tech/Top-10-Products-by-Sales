# Top 10 Products by Sales

## Project Overview
This project identifies the top 10 products with the highest total sales using the Sample Superstore dataset. Microsoft Excel is used to organize, analyze, rank, and visualize product sales.

## Objective
- Identify the top 10 products by total sales.
- Practice sorting and ranking data.
- Create a PivotTable to summarize product sales.
- Visualize sales performance using a chart.

## Tools Used
- Microsoft Excel
- PivotTables
- Bar/Column Chart
- GitHub

## Dataset
The project uses the Sample Superstore dataset, which contains product names, sales figures, and other order details.

## Project Steps
1. Downloaded and opened the Superstore dataset in Excel.
2. Created a PivotTable using Product Name and Sum of Sales.
3. Sorted sales from largest to smallest.
4. Applied a Top 10 value filter.
5. Created a table showing the top 10 products.
6. Created a chart to compare their sales.
7. Formatted the table and chart for better presentation.

## Key Findings
- The Canon imageCLASS 2200 Advanced Copier ranked first in the analysis.
- Its total sales were approximately 61,599.82.
- The top 10 products together generated total sales of approximately 244,620.20.

## Deliverables
- Excel workbook containing the Top 10 analysis.
- Top 10 products table.
- Sales comparison chart.

## Skills Learned
- Data sorting and filtering
- Sales analysis
- PivotTable creation
- Ranking products by sales
- Data visualization
- Excel reporting

## Conclusion
This project demonstrates how Excel can be used to identify the best-selling products and present sales performance in a clear, understandable format.
